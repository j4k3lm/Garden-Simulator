# Python-Based Garden Simulator (v0.6.0)
DSA project: Python OOP, Stack, Queue, 2D list, Hierarchical Tree, Tree Traversal (BFS, Preorder, Inorder, Postorder).
Stack: HTML5/DOM/Vanilla JS, Tailwind (CDN), Lucide (CDN), Pyodide.

## Run
Open this folder in VS Code, install the **Live Server** extension, right-click `index.html` > *Open with Live Server*.
Code Editor tab > **Run All 1-6** > play.
